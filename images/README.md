# images/

Drop your photos here, then reference them from the page.

The four age-gate cards and the dark interstitial are image slots. In `?edit=1`
click a slot, choose a file, and the page records the path `images/<filename>`
and previews your file straight away. Copy that same file into this folder,
push, and it goes live.

Filenames: keep them lowercase with hyphens (`age-30-39.jpg`), no spaces.
Sizes: the age cards render at 236px tall on desktop, so ~800×600 is plenty.
The interstitial runs full height beside the copy — ~1200×1600 portrait.
Compress before you commit; a 4MB hero photo costs you conversions.
